# 🎲 React Ludo Board Project

A simple **React-based Ludo Board + Move Counter Application** built using React hooks and CSS.  
This project demonstrates object state management, event handling, and UI design using React. 

---

## 🚀 Features

* 🎮 Ludo-style UI with 4 colors (Blue, Yellow, Green, Red)  
* 🔢 Move counter for each player  
* ➕ Increment moves using buttons  
* ⚛️ Object-based state management using useState  
* ⚡ Real-time UI updates  
* 🎨 Dark themed modern UI  

---

## 🛠️ Tech Stack

* React.js (useState Hook)  
* JavaScript (ES6+)  
* CSS3 (Flexbox, Styling, Layout)  
* HTML5 (JSX Structure)  
* Vite (Build Tool)

## ⚙️ How to Run This Project

### 1. Clone the repository
```
git clone https://github.com/godhaniyaarbham2000-spec/ReactJS-Project-Ludo-Board.git
```



### 2. Move to project folder
```
cd ReactJS-Project-Ludo-Board
```



### 3. Install dependencies
```
npm install
```



### 4. Start development server
```
npm run dev
```

---

## 💡 Usage

- Open the project in browser  
- You will see Ludo board UI  
- Click on any color **+1 button**  
- Each click increases move count  
- Track moves for Blue, Yellow, Green, Red  
- UI updates instantly
